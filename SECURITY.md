# Security policy

Please do not file public issues for suspected vulnerabilities. Report them privately to the repository maintainers with a minimal reproduction, affected version, and impact. Do not include credentials, customer data, or task artifacts.

Supported releases are the latest minor version on the current major line. Security fixes are released with a changelog entry and, when practical, a patched package version.

CBX executes external coding tools and optional plugins. Treat workspaces, plugins, and task inputs as trusted unless you run them in an independently managed OS sandbox.
